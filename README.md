Exploratory data analysis of a real Brazilian marketplace, Olist.
This project was completed as part of a product analyst portfolio.

Goal

Identify sales patterns and provide data-driven recommendations.

Key Findings

* Sales peak occurs in November
* The top 5 days by number of orders are November 24–28 (Black Friday period)
* Recommendation: increase marketing efforts and inventory levels
    2 weeks before Black Friday

Tools

* Python
* Pandas
* Matplotlib
* SQLite

What Was Analyzed

* Order dynamics by month
* Top days by number of orders
* Order geography by city
* Customer review analysis
* Revenue by product category

Data

Dataset: Brazilian E-Commerce Public Dataset by Olist￼
